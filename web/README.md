# Gentlemen Loyalty — بطاقة ولاء صالون حلاقة

موقع ولاء رقمي: أربع تحليقات والخامسة مجاناً، مع QR وإشعارات ولوحة للصالون.

## التشغيل محلياً

```bash
cd web
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000)

- تسجيل عميل من الصفحة الرئيسية
- البطاقة: `/card/رقم-العضوية`
- لوحة الصالون: `/staff` — الرمز الافتراضي `1234`

## الرفع على Vercel (مجاني)

1. ارفع مجلد `web` (أو المستودع كامل) على GitHub.
2. في Vercel: **Add New Project** → اختر المستودع.
3. **Root Directory** = `web` إذا كان المشروع داخل فولدر.
4. Environment Variables:
   - `STAFF_PIN` = رمز دخول الصالون
   - `NEXT_PUBLIC_SITE_URL` = رابط موقعك بعد النشر مثل `https://xxx.vercel.app`
5. Deploy.

أو من الجهاز داخل `web`:

```bash
npx vercel
```

## ملاحظات مهمة

- التخزين الحالي ملف JSON (`data/store.json` محلياً، و`/tmp` على Vercel). مناسب للتجربة والصالون الصغير.
- على Vercel البيانات قد تتصفر عند Cold Start أحياناً — لاحقاً نربط قاعدة مجانية (Neon / Supabase) للثبات الكامل.
- الإشعار: يظهر على بطاقة العميل فوراً (تحديث تلقائي كل 4 ثوان) + إشعار متصفح إن سمح العميل.
