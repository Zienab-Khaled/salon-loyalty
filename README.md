# بطاقة ولاء صالون الحلاقة — Gentlemen

> الشرح + الموقع جاهز للرفع على **Vercel مجاناً**.

## المطلوب باختصار

نظام ولاء مثل كوبونات الكوفيهات، لـ**صالون حلاقة رجالي**:

| العنصر | التفاصيل |
|--------|----------|
| الفكرة | كل تحليقة = ختم على البطاقة |
| العرض | **4 تحليقات → الخامسة مجاناً** |
| الشكل | موقع ويب (موبايل أولاً) بثيم أسود/ذهبي |
| التعريف | **QR** + رقم عضوية |
| الإشعار | يظهر للعميل عند إضافة تحليقة (+ إشعار متصفح) |

## تشغيل الموقع

```bash
cd web
npm install
npm run dev
```

- الصفحة الرئيسية: تسجيل عميل
- البطاقة: `/card/رقم-العضوية`
- لوحة الصالون: `/staff` — الرمز `1234`

## الرفع على Vercel

1. ارفع المشروع على GitHub.
2. Import في Vercel واختر Root Directory = `web`.
3. أضف المتغيرات:
   - `STAFF_PIN`
   - `NEXT_PUBLIC_SITE_URL` = رابط Vercel النهائي
4. Deploy.
